# 내 화장대

> 내 루틴의 성분 궁합을 읽어주는 **스킨케어 성분 교육 · 루틴 관리 앱** (모바일 웹 우선)

## 서비스 주제

- **무엇을 하나요?** 내가 쓰는 스킨케어 제품을 아침/저녁 루틴에 담으면, 성분 조합의 궁합 점수(0~96)와 근거를 알려주고, 내 피부 고민·타입에 맞는 다음 제품을 추천합니다. 성분 백과, 고민별 집중 관리, 피부 컨디션 일지와 인사이트, 커뮤니티 게시판, 메이크업 튜토리얼을 함께 제공합니다.
- **무엇이 아닌가요?** 의료 진단·치료 앱이 아닙니다. 모든 점수와 인사이트는 참고용 근사치이며, 성분 반응은 개인차가 있습니다. 심한 자극이나 트러블이 지속되면 전문의 상담을 권합니다.

## 정보구조 (하단 내비게이션 5탭)

| 탭 | 내용 |
|---|---|
| 홈 | 오늘의 루틴 궁합 요약, 오늘의 성분 카드, 커뮤니티·튜토리얼 미리보기 |
| 내 제품 | 제품 검색/등록, 아침·저녁 루틴, 성분 궁합 분석, 내 피부 궁합 기록, 고민 기반 추천 |
| 성분 | 성분 검색 + 카테고리 필터 + 성분 상세 |
| 관리 | 피부 고민별(8종) 집중 관리와 추천 성분 |
| 기록 | 피부 컨디션 일지, 타임라인, 인사이트 분석 |

전체 화면 오버레이: 온보딩, 커뮤니티 게시판(다른 사람들의 화장대), 메이크업 튜토리얼(눈화장/블러셔/코쉐딩).

## 기술 스택

- React 19 + Vite + TypeScript (SPA, 상태 기반 화면 전환)
- 상태 관리: zustand, 저장소 추상화(`Repository`) 뒤에 localStorage → Supabase 순으로 교체
- 배포: Vercel / 데이터: Supabase (6차시 이후)

## 개발 차시

| 차시 | 단계 | 목표 |
|---|---|---|
| 1 | 준비 | 저장소 초기화, 스캐폴딩, 서비스 주제 확정 |
| 2 | 프론트 | 하단 내비게이션 + 페이지 뼈대, 온보딩 |
| 3 | 프론트 | 제품 검색/등록 폼, 성분 백과 검색, 입력값 검증 |
| 4 | 프론트 | 성분 궁합 점수 엔진, 고민 기반 추천 엔진 |
| 5 | 프론트 | 결과 화면 완성, Vercel 첫 배포 |
| 6 | 서버·DB | Supabase 프로젝트 생성·연결 |
| 7 | 서버·DB | localStorage → Supabase read/write 교체 |
| 8 | 서버·DB | 재방문 시 저장 데이터 복원 |

## 실행

```bash
npm install
npm run dev
```

`npm run build` 로 타입 검사 + 프로덕션 빌드, `npm test` 로 엔진 단위 테스트를 실행합니다.

## 데이터 신뢰성 안내

- 제품·성분 데이터는 데모용 시드이며 "미검증" 표기를 유지합니다.
- "안전하다", "피부가 좋아진다" 같은 단정 표현을 쓰지 않습니다. 대신 "일반적으로 사용되는 성분", "반응은 개인차가 있을 수 있어요" 톤을 유지합니다.
